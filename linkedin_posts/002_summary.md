Which decisions should an AI agent make, and which should stay in code?

The first version of my job-search workflow was plain Python and direct LLM SDK calls. I controlled every component—including the loops. As it grew, those connections became harder to follow and maintain.

In episode two, I share how I moved to LangGraph for orchestration and LangChain for model integration, tools, and structured responses.

You'll see how the workflow loop and search agent loop fit together, where each agent's responsibility ends, and what a real run produces—with diagrams, code, and example results.
